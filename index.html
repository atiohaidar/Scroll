Pakai HP Kamu Jadi Trackpad Laptop

Scroll adalah ekstensi Chrome yang mengubah layar smartphone menjadi trackpad nirkabel. Koneksi berjalan langsung secara peer-to-peer (P2P via WebRTC UDP) dengan latensi di bawah 5ms tanpa perlu install aplikasi APK/IPA di HP dan tanpa server pihak ketiga.

Mulai Dari Langkah 1 Repository GitHub
Langkah 1 Pasang Ekstensi di Laptop Load folder ekstensi di menu Developer Mode Chrome atau browser berbasis Chromium.
Langkah 2 Buka Controller di HP Buka halaman web controller di HP atau scan QR Code yang tampil di ekstensi.
Langkah 3 Mulai Navigasi Gunakan jari untuk scroll halus, pinch to zoom, dan navigasi tab aktif di laptop.
Tahap Persiapan

1. Cara Pasang Ekstensi di Laptop

Hanya perlu dilakukan sekali di browser laptop kamu (Chrome, Edge, Brave, atau Opera).

1

Buka Halaman Ekstensi Browser

Ketik alamat ini di bilah URL browser laptop kamu lalu tekan Enter:

chrome://extensions

Catatan: Pengguna Edge bisa menggunakan edge://extensions, Brave di brave://extensions.

2

Aktifkan Developer Mode & Load Ekstensi

  1. Nyalakan toggle Developer mode (biasanya ada di pojok kanan atas layar).
  2. Klik tombol Load unpacked di pojok kiri atas.
  3. Arahkan dan pilih folder Scroll/extension dari repositori yang sudah di-download.
  4. Ekstensi Scroll akan langsung terpasang dan aktif.
Tips: Klik icon puzzle di pojok kanan toolbar browser kamu, lalu Pin icon Scroll agar selalu terlihat dan mudah dibuka.
Konektivitas

2. Cara Menghubungkan HP ke Laptop

Tidak perlu kabel data dan tidak perlu Bluetooth pairing sistem.

1

Buka Menu Ekstensi di Laptop

Klik icon Scroll pada toolbar browser di laptop. Popup akan terbuka dan menampilkan:

  • QR Code unik untuk pairing otomatis.
  • Room Code (contoh: scr-9x4a).
  • Status koneksi (Ready / Waiting for controller).
2

Buka Controller di Smartphone

Ada 2 pilihan cara mudah untuk membuka controller di smartphone:

  1. Scan QR Code (Paling Cepat): Buka aplikasi Kamera bawaan di HP kamu, lalu arahkan ke QR Code di layar laptop. Klik link yang muncul.
  2. Buka Manual: Di browser HP (Safari/Chrome), buka link berikut:
    https://atiohaidar.github.io/Scroll/mobile/
    Masukkan Room Code 4 digit yang tampil di laptop, lalu tekan Connect.
Tanda Berhasil: Indikator status di pojok kiri atas layar HP akan berubah hijau dengan tulisan Connected dan menampilkan angka latensi (misal: 3 ms).
Kontrol & Navigasi

3. Panduan Gesture & Fitur

Cara menggunakan permukaan layar sentuh HP kamu untuk mengontrol browser di laptop.

1 Jari

Scroll / Panning 2 Arah

Sentuh dan geser 1 jari di area trackpad HP untuk menggulir halaman website ke atas, bawah, kiri, atau kanan secara presisi.

Flick & Release

Inertia Momentum Gliding

Geser jari lalu lepas dengan cepat (flick). Halaman web akan terus meluncur mulus dengan deselerasi fisik seperti trackpad laptop modern.

2 Jari

Pinch to Zoom Kontinu

Gunakan 2 jari lalu rentangkan atau ciutkan untuk memperbesar dan memperkecil seluruh dokumen web (100% sampai 300%) tanpa merusak scrollbar.

Bilah Atas

Remote Tab Switcher

Daftar tab yang sedang terbuka di laptop otomatis sinkron ke HP. Cukup tap pada strip tab di layar HP untuk berpindah tab seketika.

Tombol Nat ↕

Arah Scroll (Natural vs Wheel)

Tap tombol Nat ↕ di header HP untuk switch antara mode Natural (jari dorong konten seperti touchscreen) dan mode Wheel (seperti roda mouse tradisional).

Haptic

Getaran Umpan Balik

HP akan memberikan getaran halus (haptic feedback) saat terhubung, saat berganti tab, dan saat zoom melewati batas 100%.

Solusi Masalah

Bantuan & Troubleshooting

Jawaban cepat untuk kendala yang mungkin kamu temui.

Kenapa scroll tidak jalan di tab tertentu?

Browser Chrome memiliki kebijakan keamanan yang melarang ekstensi menjalankan skrip di halaman sistem internal (seperti chrome://extensions, chrome://settings, Chrome Web Store, atau New Tab kosong). Cobalah buka tab website biasa (misal: Wikipedia, Google, YouTube, atau portal berita) untuk mulai scrolling.

Status di HP terus menunjukkan "Connecting..." dan tidak berubah hijau?

Pastikan HP dan laptop kamu terhubung ke jaringan Wi-Fi / Hotspot yang sama atau keduanya memiliki koneksi internet aktif. Jika masih belum terhubung, coba tutup tab popup di laptop lalu buka kembali untuk membuat Room ID baru, kemudian scan ulang QR code.

Bagaimana agar tampilan di HP menjadi Fullscreen (tanpa address bar browser)?

Di Safari (iPhone), tap tombol Share lalu pilih Add to Home Screen. Di Chrome (Android), tap menu titik tiga lalu pilih Install App atau Add to Home Screen. Ini akan membuka Scroll dalam mode Progressive Web App (PWA) layar penuh yang imersif.
